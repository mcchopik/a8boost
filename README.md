# A8Boost

Клиентский Fabric-мод для Minecraft 26.2, настроенный под Windows-систему с AMD
A8-9600, встроенной Radeon R7 и 8 ГБ ОЗУ. Это самостоятельный мод: Sodium,
Lithium и другие проекты внутрь JAR не включены.

## Что оптимизируется

- При первом запуске один раз применяется профиль: Fast, 7 чанков отрисовки,
  5 чанков симуляции, 60 FPS, облака и тени сущностей выключены, дальность
  сущностей 60%, mipmap 2, без ambient occlusion, blur и biome blending.
- Частицы отбрасываются до создания по бюджету и расстоянию. Ближние эффекты
  получают небольшой резерв, чтобы бой не становился нечитаемым.
- Подготовка обычных block entity ограничивается расстоянием. Отдельный
  off-screen pass (например, маяки) не ломается.
- Среднее время кадра проверяется с гистерезисом. При просадках лимиты переходят
  из normal в pressure/critical, после восстановления возвращаются постепенно.

## Установка

1. Установить Minecraft 26.2, Fabric Loader 0.20.1+, Fabric API и Java 25 x64.
2. Скачать `a8boost-1.0.0+26.2.jar` из артефакта последней GitHub Actions сборки.
3. Положить JAR в `%AppData%\\.minecraft\\mods`.
4. Выделить игре 4096 МБ памяти и хранить игру на SSD KINGSTON, а не на HDD.

Настройки находятся в `config/a8boost.json`. `applyHardwareProfile` и
`adaptiveTuning` можно отключить. Профиль не применяется повторно, пока
`profileApplied` не будет вручную изменён на `false`.

Мод совместим по назначению с Sodium/Lithium, но не требует их. Реальный прирост
зависит от мира, разрешения, драйвера AMD и остальных модов; JAR не может
увеличить физические 495 МБ видеопамяти.

## Сборка

Сборка и тесты выполняются на GitHub Actions. Локальная команда для разработчиков:

```bash
./gradlew build
```
